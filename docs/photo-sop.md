# 病灶拍照 SOP：N0 錨定協定（同仁一頁版）

## 口訣

> **先拍卡、再拍灶；換病人、重新拍卡。**

## 步驟

1. 手機連**診所 Wi-Fi**，點主畫面的「診間快照」（第一次用：掃護理站牆上的 QR code，加入主畫面）。
2. **N0 起手式**：第一張把**健保卡和病灶一起入鏡**（卡片放病灶旁、字面朝上、不反光）。
3. 繼續連拍病灶特寫（N1、N2…），這些**不用**再拍卡。
4. 按「確認送出」。畫面跳出辨識到的身分證字號 → **核對是這位病人** → 按「是，帶入」。
5. 換下一位病人 = 回到步驟 2，**重新拍卡**。

## 三條鐵律

| 鐵律 | 原因 |
|---|---|
| 一批只拍一位病人 | 系統偵測到一批裡有兩個不同證號會整批退回人工，等於白拍 |
| 換病人一定重新 N0 | 身份不會跨批延續——這是防止照片歸錯人的設計，不是 bug |
| 只用系統拍，不用相機 App | 系統拍的照片不會存進你的手機相簿；相機 App 拍的會，事後要自己刪還可能同步上雲 |

## 常見狀況

- **卡片辨識失敗**：重拍一張（對準、放大、避免反光），或按「手動輸入」打病歷號／證號。
- **病人沒帶健保卡／新生兒沒有證號**：手動輸入。
- **拍完才發現選錯人**：告訴管理者，在「待確認佇列」裡一鍵改派，照片會移到正確病人名下並留稽核紀錄。
- **手機連不上**：確認連的是診所 Wi-Fi（不是 4G/5G），重掃一次 QR。
